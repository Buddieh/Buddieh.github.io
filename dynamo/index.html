Projects / Dynamo

Dynamo scripts for Revit.

Graphs I wrote for my own Revit work, free to use. Each one runs from Dynamo Player and needs no packages.

Install

  1. Download a .dyn file below and save it in a folder of your choice.
  2. In Revit, open Manage › Dynamo Player and point it at that folder.
  3. Click Run next to the script.

All scripts are tested on Revit 2025; versions in dashed tags aren't tested yet. On Revit 2027, open the graph once in Dynamo and save it, so the Python engine upgrade is kept.

Scripts

Sheet Exporter

Export PDFs and DWGs from the sheets you pick, all from one dialog.

What it does

  • Pick sheets by search, All/None, or Revit's saved sheet sets
  • PDF with Revit's own export options, or a PDF setup saved in the model
  • DWG from any saved export setup, one file per sheet, no xrefs
  • File names from sheet parameters, e.g. {Sheet Number} - {Sheet Name}

Good to know

  • Remembers your options, folder and name pattern between runs
  • Cancel stops after the current file and can delete what it made
  • If Player skips the dialog on a second run, run it once from Dynamo

Smart Dimensions

Chained dimension strings for masonry plans, from grid to grid.

What it does

  • Dimensions along every line you drew in a chosen path line style
  • Picks up wall faces, wall ends and opening jambs, with door and window heights
  • A second line style gives overall grid-to-grid strings
  • Works with walls and columns from linked models

Before you run

  • Make two line styles, e.g. DIM-PATH and DIM-PATH-OVERALL
  • Curved walls and walls at an angle to the path are skipped
  • Families are dimensioned by their outline only
