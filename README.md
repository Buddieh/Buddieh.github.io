# Buddieh.github.io

Personal site, served at https://buddieh.com/ (GitHub Pages, custom domain in `CNAME`).

## Paths served by other repos

Every public repo of `Buddieh` with GitHub Pages turned on is served at
`https://buddieh.com/<repo-name>/`. Don't add a folder with one of these names to this repo:

- `/Solid-to-SCAD/`, `/mindful_usage/`, `/Persian_environment/`
- `/stained-glass/`: reserved for the Stained Glass Generator (repo `Buddieh/stained-glass`)
