Connect Game Log to Notion

← Game Log

Game Log saves each entry as a page in a Notion database. You need three things for the ⚙ Setup panel: a small relay URL, a Notion integration secret, and the database ID. It takes about ten minutes, once, and both services are free.

Why a relay? Browsers aren't allowed to call Notion's API directly from a web page, so a tiny Cloudflare Worker passes the request along. It stores nothing: your secret stays on your device and is sent with each save.

1Create a Notion integration

  1. Open notion.so/profile/integrations and click New integration.
  2. Give it a name (for example Game Log), pick your workspace, and keep the type Internal.
  3. Under Capabilities, make sure Read content and Insert content are on. Save.
  4. Copy the Internal Integration Secret (it starts with ntn_ or secret_). This goes in Notion integration secret.

Treat the secret like a password. Don't paste it into any file you upload or host.

2Make the database and share it

  1. In Notion, create a new page and choose Database → Table (a full-page database works best).
  2. Keep the title column named exactly Name. Game Log writes the game title there and puts your notes inside the page.
  3. Open the database's ••• menu (top right) → Connections → find your integration and confirm. Without this step Notion answers “object not found”.
  4. Copy the link to the database (Share → Copy link). The ID is the 32-character string before ?v=:
    notion.so/yourspace/1a2b3c4d5e6f…?v=…
    This goes in Notion database ID.

3Deploy the relay (Cloudflare Worker)

  1. Sign in at dash.cloudflare.com (a free account is enough).
  2. Go to Workers & Pages → Create → Worker, start from the “Hello World” template, name it, and click Deploy.
  3. Click Edit code, replace everything with the code below, and click Deploy again.
  4. Copy the worker's address (https://….workers.dev). This goes in Relay (Cloudflare Worker) URL.
worker.js
// Game Log relay: forwards requests to the Notion API and adds CORS headers.
// It stores nothing. The Notion secret comes from the app with each request.
const ALLOWED_ORIGIN = '*'; // or 'https://buddieh.com' to accept only this site

export default {
  async fetch(request) {
    const cors = {
      'Access-Control-Allow-Origin': ALLOWED_ORIGIN,
      'Access-Control-Allow-Methods': 'GET, POST, PATCH, OPTIONS',
      'Access-Control-Allow-Headers': 'Authorization, Notion-Version, Content-Type',
    };
    if (request.method === 'OPTIONS') return new Response(null, { headers: cors });

    const url = new URL(request.url);
    if (!url.pathname.startsWith('/v1/')) {
      return new Response('Game Log relay is running.', { headers: cors });
    }

    const res = await fetch('https://api.notion.com' + url.pathname + url.search, {
      method: request.method,
      headers: {
        'Authorization': request.headers.get('Authorization') || '',
        'Notion-Version': request.headers.get('Notion-Version') || '2022-06-28',
        'Content-Type': 'application/json',
      },
      body: request.method === 'GET' ? undefined : await request.text(),
    });

    return new Response(res.body, {
      status: res.status,
      headers: { ...cors, 'Content-Type': 'application/json' },
    });
  },
};

4Fill in Setup and test

  1. Back in Game Log, open ⚙ Setup and paste the three values.
  2. Click Save settings, then Test connection. You should see “Connected!”.

Settings are saved in this browser only, so repeat step 4 on each phone or computer you use.

If the test fails: “object not found” means the database isn't shared with the integration (step 2.3) or the ID is wrong. “API token is invalid” means the secret was copied incompletely. A network error usually means the relay URL is wrong or the worker wasn't redeployed after pasting the code.

That's it. Dictate your notes and press Save to Notion →.
